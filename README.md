# Air Sense - Hardware

O projeto Air Sense foi desenvolvido para medir a qualidade do ar em centros urbanos. Para isso hardware desenvolvido conta com uma série de sensores capazes de identificar certos tipos de gases no ambiente, tais como, CO e NO2.

Este repositório contém os arquivos fontes do projeto de Hardware.

---

## Detalhes de Hardware

|  Item           |Descrição |
|-----------------|------------|
| Tensão de entrada   |  9V - 25V    |
| Tamanho da placa      | 16.5mm x 31mm|
| Controlador principal            | STM32F108 |
| Módulo GSM       | SIM800L            |
| Sensor de umidade, temperatura e pressão       | BME280            |
| Sensor de CO, NO2 e NH3        | MICS 6814            |
